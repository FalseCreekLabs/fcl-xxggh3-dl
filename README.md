# mrkup

**[Download mrkup for Windows](../../releases/latest/download/mrkup-Setup.exe)**

One installer for every Windows 10 or 11 PC (Intel, AMD or ARM). It picks the right version itself and needs no administrator rights.

1. Run `mrkup-Setup.exe`.
2. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
3. Open mrkup from the Start menu or the desktop, or hold **Shift**, right-click a document and choose **Compare with mrkup**.

mrkup keeps itself up to date: when a new version is ready it offers **Restart**, or installs the next time you close it.
